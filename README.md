# crafting-calculator

自动化建造游戏通用合成计算器:输入目标物品与生产速度,自动构建合成树,计算所需设备数量与基础原料消耗。

适用于以"配方 + 设备"为核心的自动化建造游戏(如工厂类游戏)。配方数据以 YAML 存放,可同时维护多个游戏的配方文件,通过终端命令切换使用。

## 功能特点

- **自动规划生产链**:给定物品与速度,递归展开配方,输出完整合成树、设备统计与基础原料消耗
- **表达式解析速度**:支持数学表达式与时间单位,如 `15/min`、`8*3/2`,统一换算为 个/秒
- **多路径对比**:同一物品存在多种生产配方时,自动按设备总数最少选择主路径;可查看替代路径并切换
- **配方管理**:终端内增删改查配方,数据即文件,无需改代码
- **多游戏配方切换**:`recipes/*.yaml` 每文件一套配方,`use` 命令随时切换,选择持久化到 `config.yaml`
- **无状态单步命令**:每条命令独立执行、不缓存业务状态,行为可预期

## 快速开始

### 运行

```bash
python main.py
```

启动后进入交互式终端,示例会话:

```
> games
可用配方文件:
  1. example
  2. test

> calc 铁锭 15/min
找到 2 条生产路径，显示主路径:

============================================================
生产链: 铁锭 (0.25/s)
============================================================
#1 铁锭: 0.25/s
│设备数: 1(0.0025)
│设备: 电弧炉
└─#2 铁矿石: 0.25/s

基础原料消耗:
--------------------------------------------------
铁矿石: 0.25/s
--------------------------------------------------

设备统计:
--------------------------------------------------
电弧炉: 1(0.0025) 台
--------------------------------------------------
```

### 常用命令

| 命令 | 说明 |
|---|---|
| `games` | 列出所有配方文件 |
| `use <文件名>` | 选择配方文件(持久化到 config.yaml) |
| `game` | 显示当前配方文件 |
| `calc <物品> <速度>` | 计算生产链(主路径) |
| `alts <物品> <速度> <节点编号>` | 查看节点替代路径 |
| `use-path <物品> <速度> <节点编号> <路径编号>` | 切换到指定替代路径 |
| `items` | 列出所有物品 |
| `recipes [页码] [搜索词]` | 列出配方 |
| `recipe <名称>` | 查看配方详情 |
| `recipe add <名称> --device <设备> --inputs <列表> --outputs <列表>` | 新增配方 |
| `recipe set-device / set-inputs / set-outputs <名称> ...` | 修改配方 |
| `recipe delete <名称>` | 删除配方 |
| `help` | 显示所有命令 |
| `quit` / `exit` / `q` | 退出 |

物品列表格式:`物品:表达式,物品:表达式`(表达式可省略,默认为 1)。命令大小写不敏感。

## 配方文件格式

配方文件位于 `recipes/` 目录,一个配方条目由设备、输入、输出组成(`amount` 为换算后的每秒数量,`expression` 为原始表达式):

```yaml
铁矿冶炼:
  device: 熔炉
  inputs:
    铁矿石:
      amount: 10.0
      expression: '10'
    煤炭:
      amount: 5.0
      expression: '5'
  outputs:
    铁锭:
      amount: 5.0
      expression: '5'
```

无输入配方表示基础原料采集(如 `铁矿石采集`,设备 `铁矿场`)。

## 表达式语法

速度支持数学表达式与时间单位:

- 数学表达式:`8*3/2`、`(10+5)*2/60`
- 时间单位:`15/min`、`2.5*3.14/h`
- 单位:`s`/`sec`/`second`、`m`/`min`/`minute`、`h`/`hour`
- 函数与常量:`sin`、`cos`、`sqrt`、`pow`、`abs`、`round`、`pi`、`e`

所有表达式最终换算为 **个/秒**。

## 项目结构

```
├── main.py                   # 主程序入口(终端 REPL)
├── io_interface.py           # IO 抽象层(IOInterface / TerminalIO)
├── application_controller.py # 无状态命令分发
├── calculator.py             # 核心计算引擎(合成树、设备数)
├── crafting_node.py          # 合成树节点
├── path_engine.py            # 路径对比引擎(主/替代路径)
├── recipe_analyzer.py        # 配方分析(净产出、配方类型等)
├── byproduct_pool.py         # 副产品池
├── expression_parser.py      # 表达式与时间单位解析
├── data_manager.py           # 配方 YAML 加载/保存/搜索
├── config_manager.py         # 配置持久化(config.yaml)
├── shared/                   # 公共工具(树遍历、格式化等)
├── recipes/                  # 配方文件(YAML)
└── tests/                    # pytest 测试
```

## 备注

- 配方文件与配置文件均使用 YAML 格式(`.yaml` / `.yml`)
- 基础原料指没有配方可以生产的物品
- 主路径选择标准:总设备数最少 > 配方数更少 > 先找到的路径
- 替代路径切换(`alts`/`use-path`)每次都重新计算,不依赖前序 `calc` 结果
